## Порівняння підходів до стилізації (ПР № 6)

Для цього проєкту класичний підхід із CSS-файлами є швидшим і зручнішим, оскільки структура застосунку невелика та не вимагає складного динамічного стилювання. Проте використання Styled Components показало значні переваги при роботі з пропсами: ми змогли легко змінювати колір пріоритету без написання додаткових CSS-класів. У майбутньому для масштабованого React-проєкту варто обирати Styled Components за відсутність конфліктів імен та високу гнучкість.

## Файл даних

- **Розташування**: Файл даних `tasks.json` розташований у папці `data/` в корені проєкту (`data/tasks.json`).
- **Поведінка при відсутності**: Якщо файл відсутній, застосунок автоматично створює його разом із необхідною папкою (завдяки `{ recursive: true }`) та записує туди порожній масив `[]`.
- **Прапорець `wx`**: Використовується прапорець `wx` при відкритті/створенні файлу (`fs.open`). Він гарантує, що файл буде відкрито лише для запису, а якщо файл вже існує — операція завершиться помилкою і не перезапише існуючі дані користувача.
